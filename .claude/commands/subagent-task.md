# /subagent-task — サブエージェント委譲テンプレート

以下のタスクをサブエージェントに委譲してください。

## 委譲タスクの定義

現在の作業を分析し、サブエージェントに委譲可能な部分を特定して、以下のテンプレートで分割してください。

### テンプレート

各サブエージェントタスクは以下の形式で定義する:

```
### Sub-agent Task [N]: [タスク名]
**Goal**: [具体的な達成目標を1行で]
**Scope**: [対象ファイル・ディレクトリのリスト]
**Output**: [成果物の保存先パス]
**Constraint**:
- [制約1]
- [制約2]
**Verification**: [完了条件・検証方法]
```

## ルール

1. **単一責務**: 各サブエージェントは1つの明確な目標のみ持つ
2. **ファイル出力**: 結果はコンテキストに戻さず、ファイルに書き出す
3. **並列実行**: 依存関係のないタスクは同時に実行する
4. **禁止**: `CLAUDE.md`, `.env`, `credentials.json` の変更
5. **統合**: メインエージェントがすべての成果物をレビュー後にコミット

## 実行フロー

1. 上記テンプレートでタスクを定義する
2. 各タスクをサブエージェントに割り当てる
3. 成果物を収集・レビューする
4. 品質チェック後に統合・コミットする

## よくある委譲パターン

| パターン | サブエージェントの役割 | メインの役割 |
|---------|-------------------|------------|
| リファクタリング | 個別ファイルの修正 | diff確認・統合 |
| ドキュメント | セクション別に執筆 | 構成・体裁統一 |
| テスト作成 | テストケース実装 | カバレッジ確認 |
| コード分析 | ファイル別スキャン | 結果サマリー作成 |
