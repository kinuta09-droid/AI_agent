# 新機能: 見つけたSkill(便利ツール)の紹介記事を自動で下書きしてくれる

## これは何?

ARMSには以前から「Skill Radar」という機能があり、毎週日曜の朝に自動でGitHubを見回って
「これ、うちのAIエージェントに取り入れると良さそうかも」というツール(Skill)候補を
見つけてきてくれていました。ただしこれまでは、候補の一覧を出すところまでで、
そこから先(SNSやnoteで紹介する記事にする作業)は手作業でした。

今回追加したのは、その一覧の中から気になった候補を1つ選ぶだけで、
**X(旧Twitter)投稿の下書きと、note.com記事の下書きを自動で作ってくれる**機能です。
論文を紹介する `/paper-digest` 機能と、まったく同じ考え方・同じ仕上がりの下書きが、
Skill候補についても作れるようになりました。

## どう使うか

Skill Radarの一覧を見て「これ面白いな」と思った候補があれば、その番号を指定して
コマンドを実行するだけです。

```
py tools/tool_skill_digest.py --index 1 --mode both
```

- `--index 1` : 一覧の1番目の候補を選ぶ、という意味(2番目なら`--index 2`)
- `--mode both` : X投稿とnote記事の両方を作る、という意味(片方だけでも可)

実行すると、Obsidianの `40_Report/Skills` フォルダに下書きファイルが1つ保存されます。
中身を見て、気に入らなければ直して、良ければそのままコピペして投稿する、という流れです。

## 何が変わらないか(安全面)

- **勝手に投稿されることは一切ありません**。作られるのはあくまで「下書き」で、
  実際にXやnoteに公開するかどうかは、必ず人間(あなた)が最後に判断します。
- 毎週日曜の自動巡回(Skill Radarの一覧作成)の動きは今までと何も変わっていません。
  今回追加したのは「一覧の中から選んで、記事にする」という後工程だけです。
- 使っているのは、Skill Radarが候補を見つけたときに元々作っていた情報
  (リポジトリの説明文・トピック・AIによる「うちに合うか」の一言コメント)だけです。
  新しく追加の情報収集をしたり、追加でAIに何かを聞きに行ったりはしていません
  (=普段の使用量から大きく増えることはありません)。

## こんなときに使うと良さそう

- 週次のSkill Radar通知を見て「これは紹介したい」と思った候補が出てきたとき
- SNSやnoteのネタ探しに時間を使いたくないとき(下書きまでは自動、仕上げだけ自分で)
