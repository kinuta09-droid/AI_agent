# 新機能: 似たメモが3つ以上溜まったら、1つのまとまったノートにしませんか?と提案してくれる

## これは何?

Obsidianの `00_inbox` フォルダには、日々思いついたことをとりあえず書き留めた
「走り書きメモ(Fleeting Note)」がどんどん溜まっていきます。同じテーマについて
何度もメモしていても、それに気付いて1つのまとまったノートに整理する作業は、
今まで完全に手作業でした。

今回追加したのは、毎晩そのメモたちを見回して「これとこれとこれ、同じ話をしてるな」
という組み合わせ(3件以上)を自動で見つけ出し、AIに草稿(下書き)を書かせて、
Discordで**あなたに確認を取ってから**1つのまとまったノート(Evergreen Note、
`30_Main` フォルダ)に統合してくれる機能です。

Vaultが「思いついたことを書き捨てる場所」から「知識が育っていく場所」に
一歩近づく機能、というイメージです。

## どう使うか

特別な操作は要りません。毎晩3時45分ごろに自動で見回りが行われ、似たメモが
3件以上見つかったときだけDiscordに通知が届きます。

```
🌱 ノート昇格の提案: 「(AIが考えたタイトル)」
> (1〜2行の要約)

統合対象 (3件):
- [[メモA]]
- [[メモB]]
- [[メモC]]

[✅ 承認して恒久化]  [❌ 却下]
```

- **✅ 承認して恒久化** を押すと、AIが書いた統合ノートが `30_Main` に保存され、
  元の3件のメモは「どのノートに統合されたか」のタグが付いたうえで
  `50_Archive/Promoted` フォルダへ移動します。中身はそのまま残ります。
- **❌ 却下** を押すと、何も変更されません。元のメモはそのまま `00_inbox` に残ります。
  却下した組み合わせは、しばらく(2週間)は同じ内容で再提案されません。

何も反応しなくても問題ありません。似たメモが増えていなければ、その提案は
そのまま残り続けます(一晩に処理できる件数の上限は5件です)。

## 何が変わらないか(安全面)

- **必ず人間の承認を経てから統合されます**。AIが自動で判断して勝手に
  ノートをまとめたり消したりすることは一切ありません。
- 却下しても元のメモは一切変更されません。承認した場合も、元のメモ自体は
  削除されず、アーカイブフォルダへ移動するだけです(内容は保存されたままなので、
  後から見返すこともできます)。
- 対象は `00_inbox` の走り書きメモだけです。すでに整理済みのノート(`30_Main` 等)は
  対象になりません。
- AIへの問い合わせは、統合ノートの下書きを作るときの1回だけです
  (対象メモの本文がきちんと読めなかった場合は、AIには問い合わせずスキップします)。

## こんなときに使うと良さそう

- 「そういえば同じようなことを前にもメモしてたな」と気付いたとき、その整理を
  自動化したいとき
- 走り書きメモが溜まる一方で、まとめて見返す時間が取れていないとき
