SOP · AI-DRIVEN WEB DESIGN PRODUCTION

AI駆動型ウェブデザイン・量産ワークフロー

200サイト以上の構築実績に基づくSOP。成否はプロンプトを打つ前の「リファレンス収集」と、生成アセットを「構造的に分離・制御する設計力」で決まる。チェック項目はクリックで進捗を記録できる(このページを開き直すとリセットされる、一案件用のワーキングコピーとして使う想定)。

出典: 「AI駆動型ウェブデザイン・量産プロセス標準化マニュアル」
PHASE 1 / 5

リファレンス収集(高認知フェーズ)

主軸ツール: Pinterest / Motion Sites ・ 所要時間: 20〜30分厳守
  • レコメンド機能を辿って深掘りしながら20〜30分探索する
  • レイアウト(テキスト配置・ナビゲーション構造・情報の重なり)を集める
  • グラフィックス(蝶・枝・ふわふわ3D物体など核となるオブジェクト)を集める
  • カラー/質感(ダークグラデーション・モステクスチャ・光の当たり方)を集める
  • Figmaに解像度不問でスクリーンショットを並べ、AI指示用の構成案にする
狙い 「一つの完成サイト」ではなく3要素に分解して合成することで、デッドコピーを回避し独自のブランドアイデンティティを作る。質感はA社、レイアウトはB社、という分離がAIへの学習指示になる。
GATE → 3カテゴリそれぞれに最低数枚が揃うまで次へ進まない
PHASE 2 / 5

AIスタイル統合とアセットの構造的分離

ツール: Hickfield等の画像生成AI
  • 属性を厳格指定する:「画像1のレイアウトを維持し、画像2のテクスチャを適用せよ」
  • 不要要素は具体的に指定して排除する:「黄色の円を削除」「ナビゲーションバーを除去」
  • 背景アセットを生成: 4K/8K、テキスト・ボタン・アイコン・ロゴを完全排除
  • UI構造イメージを生成: Pure Black背景の上に配置位置のみ示す
狙い 背景=画像、UI=DOM(コード)として分離管理することで、レスポンシブ崩れとテキストの「焼き込み」歪みを防ぐ。SEOフレンドリーな構造と没入感のあるデザインを両立させる必須条件。
GATE → 背景アセットとUI構造イメージが別ファイルとして揃うまで次へ進まない
PHASE 3 / 5

Claudeによるフロントエンド実装とタイポグラフィ

プレビュー環境: Fable 5 を強制使用
  • スクショを「Top Popular Google Fonts」と照合し、フォントを人間が同定する
  • 具体的なフォント名をプロンプトに明記(例: Instrumental Serif → Google Fontsからインポート)
  • 環境指定に Pure Black Background (#000000) を必須で含める
  • Make sure everything is mobile responsive のフレーズを必ず含める
  • アイコンライブラリをimportし、ホバーエフェクト等の動的要素を付与する
狙い デザインカンプを画像として貼り付けず、テキスト・ボタンをCSS/HTMLで再構築することで検索エンジンのインデックス対象(SEO)になり、読み込み速度(LCP)が大幅に改善する。
GATE → レスポンシブ崩れなし・フォント名が具体的に固定済みになるまで次へ進まない
PHASE 4 / 5

動画生成AIによるダイナミック・バックグラウンド

任意 · 静的サイトはスキップ可
ツール: Luma / Kling
  • CleanShot等で参考サイトのモーション部分だけを数秒間録画する
  • 「色や要素は無視し、動き(Effect)の質感のみを抽出して静止画に適用せよ」と指示する
  • 10秒程度・No zoom / No zoom out でシームレスループを生成する
  • ヘッドラインを30%程度縮小し、背景の動きを邪魔しないバランスに整える
  • 既存のディバイダー線を削除する(動画自体が区切りになるため)
PHASE 5 / 5

商用クオリティへのブラッシュアップ(魂の吹き込み)

このフェーズは省略不可 — AI生成物と職人仕事の分かれ目
  • AIアーティファクト(不要なストローク/外枠・不要な塗り)をコード上で手動監査して削除
  • 背景透過させたAI生成オブジェクトをabsolute positionでセクション境界に重ねる(有機的ディバイダー)
  • セクション間パディングを200〜300px確保し、視覚的な呼吸スペースを作る
  • デスクトップ横並び要素は、モバイルでもあえて1行に小さく並べるよう個別指示する
狙い 余白の制御と不要な装飾の排除により、ユーザーは短期間でAIが構築したものと気づかず、熟練デザイナーが数週間かけたようなプロフェッショナルな印象を抱く。
リード・ウェブディレクター注記: AIモデルは日々進化するが、「リファレンスの分解」「構造の分離」「人間の審美眼による統合」という原則は普遍。常に「AIの上位に立つディレクター」としての矜持を持って制作に臨むこと。
